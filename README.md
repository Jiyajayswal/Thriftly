## Project Description

**Thriftly** is a mobile-first thrift store discovery and clothing reservation app designed to help users discover nearby thrift stores, explore their collections, and reserve clothing items for pickup.

The app provides a location-based home experience where users can browse nearby thrift stores, filter stores by distance and style, search for specific stores or clothing categories, and explore promotional offers through an interactive carousel. Each store has a dedicated profile featuring its description, location, multiple ambience photos, and a curated selection of clothing items such as vintage jackets, hoodies, denim, and shoes.

Users can open individual items to view detailed information and reserve them for pickup directly through the app. Reserved items are organized in a dedicated Bag, while notifications keep users informed about reservations and other store updates. An Account section provides access to user profile information and app settings.

Thriftly is built as a front-end prototype using React, functional components, mock JSON data, and local state management. The experience is designed with a polished, artistic fashion-editorial aesthetic rather than a conventional marketplace interface, featuring warm tones, serif typography, rounded cards, image-focused layouts, smooth transitions, and a mobile-first navigation system.

The prototype focuses on demonstrating the complete user journey from **discovering a nearby store → exploring its atmosphere and clothing → viewing an item → reserving it for pickup**, providing a realistic foundation for testing the concept with thrift store owners and potential users.
